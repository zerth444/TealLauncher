# Teal Launcher

Независимый лаунчер для Minecraft: Java Edition от Zerth. Позволяет запускать игру, управлять сборками и устанавливать моды и другое содержимое.

## Установка

Скачайте `TealLauncher-Setup.exe` в разделе [Releases](../../releases), запустите установщик и следуйте его инструкциям. Установщик поддерживает русский и английский языки. Требуется 64-битная Windows.

Для игры необходимо иметь лицензию Minecraft и войти в свой аккаунт Microsoft. Офлайн-режим предназначен для временной игры без интернета после входа в аккаунт и не заменяет лицензию.

Используя лаунчер, соблюдайте [соглашение Minecraft](https://www.minecraft.net/eula) и [правила Mojang](https://www.minecraft.net/usage-guidelines).

## Исходный код

Проект написан на C# и WPF с использованием .NET 10. Для сборки установите .NET 10 SDK и выполните `dotnet build TLauncherRemake.csproj -c Release` в Windows.
